# CaniClip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A menu bar macOS app that screenshots or records a screen area via global hotkeys, annotates screenshots, and exports PNGs and GIFs.

**Architecture:** Swift (AppKit + SwiftUI) owns every window, the menu bar item, global hotkeys and ScreenCaptureKit capture. A Rust crate `caniclip-core` owns GIF encoding (gifski) and pixelation, built as a static library and exposed to Swift through UniFFI-generated bindings. XcodeGen generates the Xcode project from `project.yml`.

**Tech Stack:** Swift 6.2 compiler in Swift 5 language mode, macOS 15 SDK, ScreenCaptureKit, KeyboardShortcuts 3.x, Rust stable, UniFFI 0.32, gifski 1.34, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-10-15-caniclip-design.md`

## Global Constraints

- Deployment target macOS 15.0; `ARCHS = arm64` only.
- Swift language mode 5 (`SWIFT_VERSION = 5.0`) to keep AppKit interop friction low; the Swift 6.2 compiler is used.
- Rust crate name `caniclip-core`, library name `caniclip_core`, UniFFI Swift module name `CaniClipCore`.
- gifski is depended on with `default-features = false, features = ["gifsicle"]` so no CLI or ffmpeg dependencies are pulled in.
- No Rust panic may cross the FFI boundary; every exported function returns `Result<_, CoreError>` or is infallible by construction.
- All annotation geometry is stored in image pixel coordinates.
- Default hotkeys: Capture Area ⌘⇧7, Record Area ⌘⇧8, Capture Full Screen ⌘⇧9.
- Recording defaults: 15 fps, quality 90, max width 1200 px, loop forever, cursor shown, max duration 60 s.
- Output file name pattern: `CaniClip YYYY-MM-DD at HH.mm.ss.<ext>`.
- Generated files (`CaniClip.xcodeproj/`, `CaniClip/Generated/`, `core/target/`, `Local.xcconfig`) are gitignored. Every task that touches the build re-runs `scripts/bootstrap.sh` before `xcodebuild`.
- Commit after every task with the trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. A drag smaller than 2×2 points (a click, or a jitter) must cancel the selection and return to idle instead of capturing a 0-pixel image. Pinned in Task 9 (`SelectionGeometry` minimum-size test).
2. A `CVPixelBuffer` whose `bytesPerRow` is padded beyond `width × 4` must still convert to a tightly packed BGRA buffer. Pinned in Task 14 (`FrameConverter` stride test).
3. A frame whose byte length does not match `width × height × 4`, or whose size differs from the first frame, must be rejected with `CoreError.InvalidInput` and not corrupt the GIF. Pinned in Task 3.
4. Pressing the Record Area hotkey while a recording is active must stop the recording, not open a second overlay. Pinned in Task 6 (`AppState.action(for:)` test).
5. A region selected on a Retina display must produce an image at 2× pixel size with the source rectangle expressed in display-local points. Pinned in Task 8 (`CaptureGeometry` tests).

```bash
#!/bin/bash
# Builds the Rust core as a static library and regenerates the UniFFI Swift
# bindings. Called by scripts/bootstrap.sh and by the Xcode pre-build phase.
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
CORE="$ROOT/core"
OUT="$ROOT/CaniClip/Generated"
export PATH="$HOME/.cargo/bin:$PATH"

# Xcode exports SDKROOT/MACOSX_DEPLOYMENT_TARGET for its own toolchain; they
# confuse cargo's build scripts for host tools, so clear them.
unset SDKROOT MACOSX_DEPLOYMENT_TARGET IPHONEOS_DEPLOYMENT_TARGET

PROFILE="${CANICLIP_RUST_PROFILE:-release}"
if [ "$PROFILE" = "release" ]; then
  (cd "$CORE" && cargo build --release --lib)
else
  (cd "$CORE" && cargo build --lib)
fi

mkdir -p "$OUT"
(cd "$CORE" && cargo run --quiet --bin uniffi-bindgen -- generate \
  --library "target/$PROFILE/libcaniclip_core.dylib" \
  --language swift \
  --config uniffi.toml \
  --out-dir "$OUT")

# Swift only discovers a Clang module through a file literally named module.modulemap.
mv -f "$OUT/CaniClipCoreFFI.modulemap" "$OUT/module.modulemap"
echo "Rust core built ($PROFILE) and Swift bindings written to $OUT"
```

```rust
    let expected_len = (width as usize) * (height as usize) * 4;
    if pixels.len() != expected_len {
        return Err(CoreError::InvalidInput {
            message: format!("expected {expected_len} bytes for {width}x{height} RGBA, got {}", pixels.len()),
        });
    }
    if block_size == 0 {
        return Err(CoreError::InvalidInput { message: "block_size must be at least 1".into() });
    }

    let x0 = x.min(width);
    let y0 = y.min(height);
    let x1 = x.saturating_add(w).min(width);
    let y1 = y.saturating_add(h).min(height);
    if x0 >= x1 || y0 >= y1 {
        return Ok(pixels);
    }

    let mut out = pixels;
    let stride = width as usize * 4;
    let mut by = y0;
    while by < y1 {
        let bh = block_size.min(y1 - by);
        let mut bx = x0;
        while bx < x1 {
            let bw = block_size.min(x1 - bx);
            let mut sum = [0u64; 4];
            for yy in by..by + bh {
                let row = yy as usize * stride;
                for xx in bx..bx + bw {
                    let i = row + xx as usize * 4;
                    for c in 0..4 {
                        sum[c] += out[i + c] as u64;
                    }
                }
            }
            let n = (bw as u64) * (bh as u64);
            let avg = [
                (sum[0] / n) as u8,
                (sum[1] / n) as u8,
                (sum[2] / n) as u8,
                (sum[3] / n) as u8,
            ];
            for yy in by..by + bh {
                let row = yy as usize * stride;
                for xx in bx..bx + bw {
                    let i = row + xx as usize * 4;
                    out[i..i + 4].copy_from_slice(&avg);
                }
            }
            bx += bw;
        }
        by += bh;
    }
    Ok(out)
```

```rust
fn settings() -> GifSettings {
    GifSettings { max_width: None, max_height: None, quality: 90, fast: true, repeat: 0 }
}

fn frame(width: u32, height: u32, shade: u8) -> Vec<u8> {
    let mut v = Vec::with_capacity((width * height * 4) as usize);
    for y in 0..height {
        for x in 0..width {
            // A moving diagonal so frames differ and gifski keeps them all.
            let on = (x + y + shade as u32) % 8 < 4;
            let c = if on { shade } else { 255 - shade };
            v.extend_from_slice(&[c, c / 2, 255 - c, 255]);
        }
    }
    v
}
```

```rust
//! Streaming GIF encoder over gifski. Frames arrive one at a time from Swift;
//! gifski's Collector/Writer pair must run on different threads, so the writer
//! thread is spawned lazily on the first frame (when the frame size is known)
//! and streams into a temp file that `finish` moves into place.

use std::fs::{self, File};
use std::io::BufWriter;
use std::path::PathBuf;
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::{Arc, Mutex};
use std::thread::JoinHandle;

use gifski::progress::NoProgress;
use gifski::{Collector, Repeat, Settings};

use rgb::RGBA8;

use crate::CoreError;

#[derive(Debug, Clone, Copy, PartialEq, Eq, uniffi::Enum)]
pub enum PixelFormat {
    Rgba,
    Bgra,
}

#[derive(Debug, Clone, uniffi::Record)]
pub struct GifSettings {
    /// Frames wider than this are downscaled to fit, aspect preserved.
    pub max_width: Option<u32>,
    /// Frames taller than this are downscaled to fit, aspect preserved.
    pub max_height: Option<u32>,
    /// gifski quality 1..=100.
    pub quality: u8,
    /// gifski fast mode: lower quality, faster.
    pub fast: bool,
    /// -1 = play once, 0 = loop forever, n = loop n times.
    pub repeat: i32,
}

#[derive(Debug, Clone, uniffi::Record)]
pub struct GifSummary {
    pub frame_count: u32,
    pub file_size_bytes: u64,
    pub duration_secs: f64,
}

enum State {
    /// No frame yet; gifski is not created because it needs the output size.
    Waiting(GifSettings),
    Running(Running),
    Finished,
}

struct Running {
    collector: Collector,
    writer: JoinHandle<Result<(), gifski::Error>>,
    temp_path: PathBuf,
    width: u32,
    height: u32,
    frame_index: usize,
    last_timestamp: f64,
}

#[derive(uniffi::Object)]
pub struct GifEncoder {
    state: Mutex<State>,
}

static TEMP_COUNTER: AtomicU64 = AtomicU64::new(0);

fn temp_gif_path() -> PathBuf {
    let n = TEMP_COUNTER.fetch_add(1, Ordering::Relaxed);
    std::env::temp_dir().join(format!("caniclip-{}-{}.gif", std::process::id(), n))
}

/// Output size that fits inside the optional maxima while preserving aspect.
fn fitted_size(width: u32, height: u32, max_w: Option<u32>, max_h: Option<u32>) -> (u32, u32) {
    let mut scale = 1.0f64;
    if let Some(mw) = max_w.filter(|m| *m > 0) {
        scale = scale.min(mw as f64 / width as f64);
    }
    if let Some(mh) = max_h.filter(|m| *m > 0) {
        scale = scale.min(mh as f64 / height as f64);
    }
    if scale >= 1.0 {
        return (width, height);
    }
    (
        ((width as f64 * scale).round() as u32).max(1),
        ((height as f64 * scale).round() as u32).max(1),
    )
}

fn to_rgba(pixels: Vec<u8>, format: PixelFormat) -> Vec<RGBA8> {
    pixels
        .chunks_exact(4)
        .map(|p| match format {
            PixelFormat::Rgba => RGBA8::new(p[0], p[1], p[2], p[3]),
            PixelFormat::Bgra => RGBA8::new(p[2], p[1], p[0], p[3]),
        })
        .collect()
}

fn start(settings: &GifSettings, width: u32, height: u32) -> Result<Running, CoreError> {
    let (out_w, out_h) = fitted_size(width, height, settings.max_width, settings.max_height);
    let repeat = match settings.repeat {
        r if r < 0 => Repeat::Finite(0),
        0 => Repeat::Infinite,
        r => Repeat::Finite(r.min(u16::MAX as i32) as u16),
    };
    let gs = Settings {
        width: Some(out_w),
        height: Some(out_h),
        quality: settings.quality,
        fast: settings.fast,
        repeat,
    };
    let (collector, writer) =
        gifski::new(gs).map_err(|e| CoreError::Encoding { message: e.to_string() })?;
    let temp_path = temp_gif_path();
    let file = BufWriter::new(File::create(&temp_path)?);
    let handle = std::thread::Builder::new()
        .name("caniclip-gif-writer".into())
        .spawn(move || writer.write(file, &mut NoProgress {}))
        .map_err(|e| CoreError::Io { message: e.to_string() })?;
    Ok(Running {
        collector,
        writer: handle,
        temp_path,
        width,
        height,
        frame_index: 0,
        last_timestamp: 0.0,
    })
}

#[uniffi::export]
impl GifEncoder {
    #[uniffi::constructor]
    pub fn new(settings: GifSettings) -> Result<Arc<Self>, CoreError> {
        if !(1..=100).contains(&settings.quality) {
            return Err(CoreError::InvalidInput {
                message: format!("quality must be 1..=100, got {}", settings.quality),
            });
        }
        Ok(Arc::new(Self { state: Mutex::new(State::Waiting(settings)) }))
    }

    pub fn add_frame(
        &self,
        pixels: Vec<u8>,
        width: u32,
        height: u32,
        format: PixelFormat,
        timestamp_secs: f64,
    ) -> Result<(), CoreError> {
        let expected = width as usize * height as usize * 4;
        if width == 0 || height == 0 || pixels.len() != expected {
            return Err(CoreError::InvalidInput {
                message: format!("expected {expected} bytes for {width}x{height}, got {}", pixels.len()),
            });
        }
        let mut guard = self.state.lock().map_err(|_| CoreError::Encoding { message: "encoder poisoned".into() })?;
        if let State::Waiting(settings) = &*guard {
            let running = start(settings, width, height)?;
            *guard = State::Running(running);
        }
        let running = match &mut *guard {
            State::Running(r) => r,
            State::Finished => return Err(CoreError::AlreadyFinished),
            State::Waiting(_) => return Err(CoreError::Encoding { message: "encoder failed to start".into() }),
        };
        if (width, height) != (running.width, running.height) {
            return Err(CoreError::InvalidInput {
                message: format!(
                    "frame size {width}x{height} differs from first frame {}x{}",
                    running.width, running.height
                ),
            });
        }
        let img = ImgVec::new(to_rgba(pixels, format), width as usize, height as usize);
        running
            .collector
            .add_frame_rgba(running.frame_index, img, timestamp_secs)
            .map_err(|e| CoreError::Encoding { message: e.to_string() })?;
        running.frame_index += 1;
        running.last_timestamp = timestamp_secs;
        Ok(())
    }

    pub fn finish(&self, output_path: String) -> Result<GifSummary, CoreError> {
        let mut guard = self.state.lock().map_err(|_| CoreError::Encoding { message: "encoder poisoned".into() })?;
        let previous = std::mem::replace(&mut *guard, State::Finished);
        let running = match previous {
            State::Running(r) => r,
            State::Waiting(_) => return Err(CoreError::Encoding { message: "no frames were added".into() }),
            State::Finished => return Err(CoreError::AlreadyFinished),
        };
        drop(guard);

        let Running { collector, writer, temp_path, frame_index, last_timestamp, .. } = running;
        drop(collector); // closes the channel so the writer drains and returns
        let write_result = writer.join().map_err(|_| CoreError::Encoding { message: "writer thread panicked".into() })?;
        if let Err(e) = write_result {
            let _ = fs::remove_file(&temp_path);
            return Err(CoreError::Encoding { message: e.to_string() });
        }

        let dest = PathBuf::from(&output_path);
        if fs::rename(&temp_path, &dest).is_err() {
            // Cross-volume move: copy then delete.
            fs::copy(&temp_path, &dest)?;
            let _ = fs::remove_file(&temp_path);
        }
        let size = fs::metadata(&dest)?.len();
        Ok(GifSummary {
            frame_count: frame_index as u32,
            file_size_bytes: size,
            duration_secs: last_timestamp,
        })
    }

    /// Abandons the recording and deletes the temp file. Safe to call at any time.
    pub fn cancel(&self) {
        let Ok(mut guard) = self.state.lock() else { return };
        let previous = std::mem::replace(&mut *guard, State::Finished);
        drop(guard);
        if let State::Running(Running { collector, writer, temp_path, .. }) = previous {
            drop(collector);
            let _ = writer.join();
            let _ = fs::remove_file(temp_path);
        }
    }
}
```

```swift
import AppKit

struct StatusMenuActions {
    var captureArea: () -> Void
    var captureFullScreen: () -> Void
    var recordArea: () -> Void
    var openSettings: () -> Void
    var quit: () -> Void
}

enum StatusMenuTag: Int {
    case captureArea = 1
    case captureFullScreen
    case recordArea
}

/// Owns the NSStatusItem. Left click opens the menu, except while recording,
/// when the icon is a red dot and a click stops the recording.
@MainActor
final class StatusItemController: NSObject {
    private let statusItem: NSStatusItem
    private let actions: StatusMenuActions
    private let menu = NSMenu()
    private(set) var isRecording = false
    var onStopRecordingClicked: (() -> Void)?

    var button: NSStatusBarButton? { statusItem.button }

    init(actions: StatusMenuActions) {
        self.actions = actions
        self.statusItem = NSStatusBar.system.statusItem(withLength: NSStatusItem.squareLength)
        super.init()
        buildMenu()
        updateIcon()
        statusItem.button?.target = self
        statusItem.button?.action = #selector(buttonClicked)
        statusItem.button?.sendAction(on: [.leftMouseUp, .rightMouseUp])
    }

    func menuItem(for tag: StatusMenuTag) -> NSMenuItem? {
        menu.item(withTag: tag.rawValue)
    }

    func setRecording(_ recording: Bool) {
        isRecording = recording
        updateIcon()
    }

    private func buildMenu() {
        menu.autoenablesItems = false
        let shortVersion = Bundle.main.object(forInfoDictionaryKey: "CFBundleShortVersionString") as? String ?? "?"
        let about = NSMenuItem(title: "CaniClip \(shortVersion) · core \(coreVersion())", action: nil, keyEquivalent: "")
        about.isEnabled = false
        menu.addItem(about)
        menu.addItem(.separator())
        menu.addItem(makeItem("Capture Area", #selector(captureArea), tag: .captureArea))
        menu.addItem(makeItem("Capture Full Screen", #selector(captureFullScreen), tag: .captureFullScreen))
        menu.addItem(makeItem("Record Area to GIF", #selector(recordArea), tag: .recordArea))
        menu.addItem(.separator())
        let settings = makeItem("Settings…", #selector(openSettings), tag: nil)
        settings.keyEquivalent = ","
        menu.addItem(settings)
        let quit = makeItem("Quit CaniClip", #selector(quit), tag: nil)
        quit.keyEquivalent = "q"
        menu.addItem(quit)
    }

    private func makeItem(_ title: String, _ selector: Selector, tag: StatusMenuTag?) -> NSMenuItem {
        let item = NSMenuItem(title: title, action: selector, keyEquivalent: "")
        item.target = self
        item.isEnabled = true
        if let tag { item.tag = tag.rawValue }
        return item
    }

    private func updateIcon() {
        let symbol = isRecording ? "record.circle.fill" : "camera.viewfinder"
        let image = NSImage(systemSymbolName: symbol, accessibilityDescription: "CaniClip")
        image?.isTemplate = !isRecording
        statusItem.button?.image = image
        statusItem.button?.contentTintColor = isRecording ? .systemRed : nil
    }

    @objc private func buttonClicked() {
        if isRecording {
            onStopRecordingClicked?()
            return
        }
        statusItem.menu = menu
        statusItem.button?.performClick(nil)
        statusItem.menu = nil
    }

    @objc private func captureArea() { actions.captureArea() }
    @objc private func captureFullScreen() { actions.captureFullScreen() }
    @objc private func recordArea() { actions.recordArea() }
    @objc private func openSettings() { actions.openSettings() }
    @objc private func quit() { actions.quit() }
}
```

```swift
import Foundation

enum FileNamer {
    private static func formatter(_ timeZone: TimeZone) -> DateFormatter {
        let f = DateFormatter()
        f.locale = Locale(identifier: "en_US_POSIX")
        f.timeZone = timeZone
        f.dateFormat = "yyyy-MM-dd 'at' HH.mm.ss"
        return f
    }

    /// `CaniClip 2026-10-15 at 11.52.03.png`
    static func fileName(date: Date = Date(), ext: String, timeZone: TimeZone = .current) -> String {
        "CaniClip \(formatter(timeZone).string(from: date)).\(ext)"
    }

    /// Same as `fileName` but appends ` 2`, ` 3`, … until the path is free.
    static func uniqueURL(in folder: URL, date: Date = Date(), ext: String,
                          timeZone: TimeZone = .current, fileManager: FileManager = .default) -> URL {
        let stem = "CaniClip \(formatter(timeZone).string(from: date))"
        var candidate = folder.appendingPathComponent("\(stem).\(ext)")
        var n = 2
        while fileManager.fileExists(atPath: candidate.path) {
            candidate = folder.appendingPathComponent("\(stem) \(n).\(ext)")
            n += 1
        }
        return candidate
    }
}
```

```swift
import AppKit
import ImageIO
import UniformTypeIdentifiers

enum ExportError: LocalizedError {
    case encodingFailed
    case writeFailed(URL, Error)

    var errorDescription: String? {
        switch self {
        case .encodingFailed: return "The image could not be encoded as PNG."
        case .writeFailed(let url, let error): return "Could not write \(url.lastPathComponent): \(error.localizedDescription)"
        }
    }
}

enum ImageExporter {
    static func pngData(from image: CGImage) throws -> Data {
        let data = NSMutableData()
        guard let dest = CGImageDestinationCreateWithData(data, UTType.png.identifier as CFString, 1, nil) else {
            throw ExportError.encodingFailed
        }
        CGImageDestinationAddImage(dest, image, nil)
        guard CGImageDestinationFinalize(dest) else { throw ExportError.encodingFailed }
        return data as Data
    }

    static func writePNG(_ image: CGImage, to url: URL) throws {
        let data = try pngData(from: image)
        do {
            try data.write(to: url, options: .atomic)
        } catch {
            throw ExportError.writeFailed(url, error)
        }
    }

    static func copyToClipboard(_ image: CGImage) {
        let item = NSPasteboardItem()
        if let png = try? pngData(from: image) {
            item.setData(png, forType: .png)
        }
        if let tiff = NSBitmapImageRep(cgImage: image).tiffRepresentation {
            item.setData(tiff, forType: .tiff)
        }
        let pb = NSPasteboard.general
        pb.clearContents()
        pb.writeObjects([item])
    }

    static func copyFileToClipboard(_ url: URL) {
        let pb = NSPasteboard.general
        pb.clearContents()
        pb.writeObjects([url as NSURL])
    }
}
```

```swift
import Foundation
import Combine

enum CaptureKind: Equatable {
    case areaScreenshot, fullScreenScreenshot, areaRecording
}

enum AppMode: Equatable {
    case idle
    case selecting(CaptureKind)
    case editing
    case recording
}

enum HotkeyAction: Equatable {
    case startSelection(CaptureKind)
    case captureFullScreenNow
    case stopRecording
    case ignore
}

/// The single source of truth for what the app is doing. Hotkeys and menu items
/// ask `action(for:)` so both paths behave identically.
@MainActor
final class AppState: ObservableObject {
    @Published private(set) var mode: AppMode = .idle

    func action(for kind: CaptureKind) -> HotkeyAction {
        switch (mode, kind) {
        case (.recording, .areaRecording): return .stopRecording
        case (.recording, _): return .ignore
        case (.selecting, _): return .ignore
        case (_, .fullScreenScreenshot): return .captureFullScreenNow
        case (_, .areaScreenshot), (_, .areaRecording): return .startSelection(kind)
        }
    }

    func transition(to newMode: AppMode) {
        mode = newMode
    }
}
```

```swift
import CoreGraphics

enum ScreenRecordingPermission {
    static var isGranted: Bool { CGPreflightScreenCaptureAccess() }

    /// Triggers the system prompt the first time; returns the current state.
    @discardableResult
    static func request() -> Bool { CGRequestScreenCaptureAccess() }

    static func openSystemSettings() {
        if let url = URL(string: "x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture") {
            NSWorkspace.shared.open(url)
        }
    }

    /// Returns true when capture may proceed. Otherwise requests access, explains
    /// the relaunch requirement, and offers to open System Settings.
    @MainActor
    static func ensureGranted() -> Bool {
        if isGranted { return true }
        if request() { return true }
        let alert = NSAlert()
        alert.messageText = "CaniClip needs Screen Recording access"
        alert.informativeText = "Turn on CaniClip under System Settings → Privacy & Security → Screen Recording, then quit and reopen CaniClip. macOS applies this permission only after a relaunch."
        alert.alertStyle = .warning
        alert.addButton(withTitle: "Open System Settings")
        alert.addButton(withTitle: "Later")
        NSApp.activate(ignoringOtherApps: true)
        if alert.runModal() == .alertFirstButtonReturn {
            openSystemSettings()
        }
        return false
    }
}
```

```swift
import AppKit

struct DisplayGeometry: Equatable {
    /// `NSScreen.frame`: global coordinates, bottom-left origin, points.
    let frame: CGRect
    /// `NSScreen.backingScaleFactor`.
    let scale: CGFloat
}

enum CaptureGeometry {
    /// ScreenCaptureKit's `sourceRect` is display-local with a top-left origin, in points.
    static func sourceRect(globalRect: CGRect, display: DisplayGeometry) -> CGRect {
        CGRect(
            x: globalRect.minX - display.frame.minX,
            y: display.frame.maxY - globalRect.maxY,
            width: globalRect.width,
            height: globalRect.height
        )
    }

    static func pixelSize(pointSize: CGSize, scale: CGFloat) -> (width: Int, height: Int) {
        (Int((pointSize.width * scale).rounded()), Int((pointSize.height * scale).rounded()))
    }

    static func screen(containing point: CGPoint, screens: [NSScreen]) -> NSScreen? {
        screens.first { $0.frame.contains(point) } ?? NSScreen.main ?? screens.first
    }
}

extension NSScreen {
    var displayID: CGDirectDisplayID {
        let key = NSDeviceDescriptionKey("NSScreenNumber")
        return (deviceDescription[key] as? NSNumber)?.uint32Value ?? 0
    }
}
```

```swift
import AppKit
import ScreenCaptureKit

enum CaptureError: LocalizedError {
    case displayNotFound

    var errorDescription: String? {
        switch self {
        case .displayNotFound: return "The display to capture could not be found."
        }
    }
}

@MainActor
final class ScreenCapturer {
    /// Captures `globalRect` (AppKit global points; nil = whole screen) on `screen`
    /// at native pixel scale. CaniClip's own windows are excluded so overlays and
    /// panels never appear in the result.
    func capture(globalRect: CGRect?, on screen: NSScreen) async throws -> CGImage {
        let content = try await SCShareableContent.excludingDesktopWindows(false, onScreenWindowsOnly: true)
        guard let display = content.displays.first(where: { $0.displayID == screen.displayID }) else {
            throw CaptureError.displayNotFound
        }
        let filter = Self.filterExcludingSelf(display: display, content: content)
        let geometry = DisplayGeometry(frame: screen.frame, scale: screen.backingScaleFactor)
        let source = CaptureGeometry.sourceRect(globalRect: globalRect ?? screen.frame, display: geometry)
        let px = CaptureGeometry.pixelSize(pointSize: source.size, scale: geometry.scale)

        let config = SCStreamConfiguration()
        config.sourceRect = source
        config.width = px.width
        config.height = px.height
        config.showsCursor = false
        config.captureResolution = .best
        config.pixelFormat = kCVPixelFormatType_32BGRA
        return try await SCScreenshotManager.captureImage(contentFilter: filter, configuration: config)
    }

    /// Content filter for `display` that hides every window belonging to this process.
    static func filterExcludingSelf(display: SCDisplay, content: SCShareableContent) -> SCContentFilter {
        let pid = ProcessInfo.processInfo.processIdentifier
        let own = content.applications.filter { $0.processID == pid }
        return SCContentFilter(display: display, excludingApplications: own, exceptingWindows: [])
    }
}
```

```swift
import Foundation

enum SelectionGeometry {
    /// Drags smaller than this in either dimension are treated as a cancelled click.
    static let minimumSize: CGFloat = 2

    static func rect(from anchor: CGPoint, to current: CGPoint, constrainSquare: Bool) -> CGRect {
        var w = current.x - anchor.x
        var h = current.y - anchor.y
        if constrainSquare {
            let side = max(abs(w), abs(h))
            w = w < 0 ? -side : side
            h = h < 0 ? -side : side
        }
        return CGRect(x: min(anchor.x, anchor.x + w), y: min(anchor.y, anchor.y + h), width: abs(w), height: abs(h))
    }

    static func isUsable(_ rect: CGRect) -> Bool {
        rect.width >= minimumSize && rect.height >= minimumSize
    }

    static func sizeLabel(for rect: CGRect, scale: CGFloat) -> String {
        let px = CaptureGeometry.pixelSize(pointSize: rect.size, scale: scale)
        return "\(px.width) × \(px.height)"
    }
}
```

```swift
import AppKit

/// Full-screen dimming view that lets the user drag out a rectangle.
/// Coordinates are window-local (AppKit, bottom-left origin); the owner converts to global.
final class SelectionView: NSView {
    var onFinished: ((CGRect?) -> Void)?   // nil = cancelled; rect is window-local

    private let scale: CGFloat
    private var anchor: CGPoint?
    private var current: CGPoint?
    private var constrainSquare = false
    private var spaceHeld = false
    private var lastDrag: CGPoint?
    private var finished = false

    init(frame: CGRect, scale: CGFloat) {
        self.scale = scale
        super.init(frame: frame)
        wantsLayer = true
    }

    required init?(coder: NSCoder) { fatalError("not used") }

    override var acceptsFirstResponder: Bool { true }
    override var mouseDownCanMoveWindow: Bool { false }

    override func resetCursorRects() {
        addCursorRect(bounds, cursor: .crosshair)
    }

    private var selectionRect: CGRect? {
        guard let anchor, let current else { return nil }
        return SelectionGeometry.rect(from: anchor, to: current, constrainSquare: constrainSquare)
    }

    override func draw(_ dirtyRect: NSRect) {
        guard let ctx = NSGraphicsContext.current?.cgContext else { return }
        ctx.setFillColor(NSColor.black.withAlphaComponent(0.35).cgColor)
        ctx.fill(bounds)
        guard let rect = selectionRect else { return }
        ctx.clear(rect)
        ctx.setStrokeColor(NSColor.white.cgColor)
        ctx.setLineWidth(1)
        ctx.stroke(rect.insetBy(dx: 0.5, dy: 0.5))
        drawSizeLabel(for: rect, in: ctx)
    }

    private func drawSizeLabel(for rect: CGRect, in ctx: CGContext) {
        let text = SelectionGeometry.sizeLabel(for: rect, scale: scale) as NSString
        let attrs: [NSAttributedString.Key: Any] = [
            .font: NSFont.monospacedDigitSystemFont(ofSize: 12, weight: .medium),
            .foregroundColor: NSColor.white,
        ]
        let size = text.size(withAttributes: attrs)
        let pad: CGFloat = 6
        var origin = CGPoint(x: rect.minX, y: rect.minY - size.height - pad * 2 - 4)
        if origin.y < 0 { origin.y = rect.maxY + 4 }
        let box = CGRect(x: origin.x, y: origin.y, width: size.width + pad * 2, height: size.height + pad * 2)
        ctx.setFillColor(NSColor.black.withAlphaComponent(0.7).cgColor)
        let path = CGPath(roundedRect: box, cornerWidth: 5, cornerHeight: 5, transform: nil)
        ctx.addPath(path)
        ctx.fillPath()
        text.draw(at: CGPoint(x: box.minX + pad, y: box.minY + pad), withAttributes: attrs)
    }

    override func mouseDown(with event: NSEvent) {
        let p = convert(event.locationInWindow, from: nil)
        anchor = p
        current = p
        lastDrag = p
        needsDisplay = true
    }

    override func mouseDragged(with event: NSEvent) {
        let p = convert(event.locationInWindow, from: nil)
        if spaceHeld, let last = lastDrag, let a = anchor, let c = current {
            let dx = p.x - last.x, dy = p.y - last.y
            anchor = CGPoint(x: a.x + dx, y: a.y + dy)
            current = CGPoint(x: c.x + dx, y: c.y + dy)
        } else {
            current = p
        }
        lastDrag = p
        needsDisplay = true
    }

    override func mouseUp(with event: NSEvent) {
        guard let rect = selectionRect else { return finish(nil) }
        finish(SelectionGeometry.isUsable(rect) ? rect.intersection(bounds) : nil)
    }

    override func keyDown(with event: NSEvent) {
        switch event.keyCode {
        case 53: finish(nil)                 // Escape
        case 49: spaceHeld = true            // Space
        default: super.keyDown(with: event)
        }
    }

    override func keyUp(with event: NSEvent) {
        if event.keyCode == 49 { spaceHeld = false }
    }

    override func flagsChanged(with event: NSEvent) {
        constrainSquare = event.modifierFlags.contains(.shift)
        needsDisplay = true
    }

    private func finish(_ rect: CGRect?) {
        guard !finished else { return }
        finished = true
        onFinished?(rect)
    }
}
```

```swift
import AppKit

enum SelectionResult {
    case cancelled
    case selected(globalRect: CGRect, screen: NSScreen)
}

/// Shows one dimming overlay per screen and reports the dragged rectangle in
/// global AppKit coordinates. Overlays are closed before `completion` runs.
@MainActor
final class SelectionOverlayController {
    private var windows: [SelectionOverlayWindow] = []
    private var completion: ((SelectionResult) -> Void)?

    func begin(completion: @escaping (SelectionResult) -> Void) {
        cancel()
        self.completion = completion
        windows = NSScreen.screens.map { screen in
            let window = SelectionOverlayWindow(screen: screen)
            window.selectionView.onFinished = { [weak self, weak window] localRect in
                guard let self else { return }
                guard let localRect, let window else { return self.finish(.cancelled) }
                let global = localRect.offsetBy(dx: window.frame.minX, dy: window.frame.minY)
                self.finish(.selected(globalRect: global, screen: window.screenTarget))
            }
            window.orderFrontRegardless()
            return window
        }
        NSApp.activate(ignoringOtherApps: true)
        let mouse = NSEvent.mouseLocation
        let keyWindow = windows.first { $0.frame.contains(mouse) } ?? windows.first
        keyWindow?.makeKeyAndOrderFront(nil)
        keyWindow?.makeFirstResponder(keyWindow?.selectionView)
        NSCursor.crosshair.set()
    }

    /// Dismisses the overlays without reporting a result.
    func cancel() {
        closeWindows()
        completion = nil
    }

    private func finish(_ result: SelectionResult) {
        let done = completion
        completion = nil
        closeWindows()
        done?(result)
    }

    private func closeWindows() {
        windows.forEach { $0.orderOut(nil) }
        windows = []
        NSCursor.arrow.set()
    }
}
```

```swift
import AppKit

/// Routes hotkey and menu requests through AppState and runs the capture flows.
@MainActor
final class CaptureCoordinator {
    let appState: AppState
    let preferences: PreferencesStore
    let statusItem: StatusItemController
    let overlay = SelectionOverlayController()
    let capturer = ScreenCapturer()

    init(appState: AppState, preferences: PreferencesStore, statusItem: StatusItemController) {
        self.appState = appState
        self.preferences = preferences
        self.statusItem = statusItem
    }

    func handle(_ kind: CaptureKind) {
        switch appState.action(for: kind) {
        case .startSelection(let k): beginSelection(k)
        case .captureFullScreenNow: captureFullScreen()
        case .stopRecording: stopRecording()
        case .ignore: break
        }
    }

    // MARK: Selection

    func beginSelection(_ kind: CaptureKind) {
        guard ScreenRecordingPermission.ensureGranted() else { return }
        appState.transition(to: .selecting(kind))
        overlay.begin { [weak self] result in
            guard let self else { return }
            switch result {
            case .cancelled:
                self.appState.transition(to: .idle)
            case .selected(let globalRect, let screen):
                switch kind {
                case .areaScreenshot:
                    Task { await self.captureScreenshot(globalRect: globalRect, screen: screen) }
                case .areaRecording:
                    self.prepareRecording(globalRect: globalRect, screen: screen)
                case .fullScreenScreenshot:
                    self.appState.transition(to: .idle)
                }
            }
        }
    }

    func captureFullScreen() {
        guard ScreenRecordingPermission.ensureGranted() else { return }
        guard let screen = CaptureGeometry.screen(containing: NSEvent.mouseLocation, screens: NSScreen.screens) else { return }
        appState.transition(to: .selecting(.fullScreenScreenshot))
        Task { await captureScreenshot(globalRect: nil, screen: screen) }
    }

    private func captureScreenshot(globalRect: CGRect?, screen: NSScreen) async {
        do {
            let image = try await capturer.capture(globalRect: globalRect, on: screen)
            deliverScreenshot(image)
        } catch {
            appState.transition(to: .idle)
            ErrorPresenter.present(error, title: "Screenshot failed")
        }
    }

    // MARK: Delivery

    func deliverScreenshot(_ image: CGImage) {
        switch preferences.preferences.afterCapture {
        case .openEditor:
            openEditor(image)
        case .copyToClipboard:
            ImageExporter.copyToClipboard(image)
            playCaptureSound()
            appState.transition(to: .idle)
        case .saveToFolder:
            do {
                _ = try saveScreenshot(image)
                playCaptureSound()
            } catch {
                ErrorPresenter.present(error, title: "Could not save screenshot")
            }
            appState.transition(to: .idle)
        }
    }

    @discardableResult
    func saveScreenshot(_ image: CGImage) throws -> URL {
        let url = FileNamer.uniqueURL(in: preferences.preferences.saveFolderURL, ext: "png")
        try ImageExporter.writePNG(image, to: url)
        return url
    }

    func openEditor(_ image: CGImage) {
        // Interim behaviour until the editor exists (Task 13): save and copy.
        do {
            let url = try saveScreenshot(image)
            ImageExporter.copyToClipboard(image)
            NSLog("Saved screenshot to \(url.path)")
            playCaptureSound()
        } catch {
            ErrorPresenter.present(error, title: "Could not save screenshot")
        }
        appState.transition(to: .idle)
    }

    private func playCaptureSound() {
        NSSound(named: NSSound.Name("Pop"))?.play()

    }
```

```swift
struct RGBAColor: Equatable, Codable {

    var cgColor: CGColor { CGColor(srgbRed: r, green: g, blue: b, alpha: a) }

    static let orange = RGBAColor(r: 1.0, g: 0.58, b: 0.0, a: 1)
    static let yellow = RGBAColor(r: 1.0, g: 0.84, b: 0.04, a: 1)
    static let green = RGBAColor(r: 0.2, g: 0.78, b: 0.35, a: 1)
    static let blue = RGBAColor(r: 0.0, g: 0.48, b: 1.0, a: 1)
    static let black = RGBAColor(r: 0, g: 0, b: 0, a: 1)
    static let white = RGBAColor(r: 1, g: 1, b: 1, a: 1)
}

struct AnnotationStyle: Equatable, Codable {
    var color: RGBAColor = .red
    var strokeWidth: CGFloat = 4
    var fontSize: CGFloat = 24
}

/// One drawn element. Geometry is in image pixels with a top-left origin.
struct Annotation: Identifiable, Equatable, Codable {
    enum Kind: Equatable, Codable {
        case arrow(from: CGPoint, to: CGPoint)
        case rect(CGRect)
        case ellipse(CGRect)
        case pen([CGPoint])
        case highlighter([CGPoint])
        case text(origin: CGPoint, string: String)
        case pixelate(CGRect, blockSize: Int)
    }

    var id: UUID
    var kind: Kind
    var style: AnnotationStyle

    init(id: UUID = UUID(), kind: Kind, style: AnnotationStyle = AnnotationStyle()) {
        self.id = id
        self.kind = kind
        self.style = style
    }

    /// Highlighter strokes are drawn this many times wider than `strokeWidth`.
    static let highlighterWidthFactor: CGFloat = 4

    /// Rough text extent used for hit testing and selection outlines.
    static func estimatedTextSize(_ string: String, fontSize: CGFloat) -> CGSize {
        let lines = string.split(separator: "\n", omittingEmptySubsequences: false)
        let longest = lines.map(\.count).max() ?? 0
        return CGSize(width: max(CGFloat(longest) * fontSize * 0.6, fontSize * 0.6),
                      height: CGFloat(max(lines.count, 1)) * fontSize * 1.2)
    }

    var boundingBox: CGRect {
        switch kind {
        case .arrow(let a, let b):
            return CGRect(x: min(a.x, b.x), y: min(a.y, b.y), width: abs(a.x - b.x), height: abs(a.y - b.y))
        case .rect(let r), .ellipse(let r), .pixelate(let r, _):
            return r
        case .pen(let pts), .highlighter(let pts):
            guard let first = pts.first else { return .zero }
            var minX = first.x, maxX = first.x, minY = first.y, maxY = first.y
            for p in pts {
                minX = min(minX, p.x); maxX = max(maxX, p.x)
                minY = min(minY, p.y); maxY = max(maxY, p.y)
            }
            return CGRect(x: minX, y: minY, width: maxX - minX, height: maxY - minY)
        case .text(let origin, let string):
            return CGRect(origin: origin, size: Self.estimatedTextSize(string, fontSize: style.fontSize))
        }
    }

    func hitTest(_ p: CGPoint, tolerance: CGFloat) -> Bool {
        switch kind {
        case .arrow(let a, let b):
            return Self.distance(from: p, toSegment: a, b) <= tolerance + style.strokeWidth / 2
        case .rect(let r), .ellipse(let r):
            let outer = r.insetBy(dx: -(tolerance + style.strokeWidth / 2), dy: -(tolerance + style.strokeWidth / 2))
            let inner = r.insetBy(dx: tolerance + style.strokeWidth / 2, dy: tolerance + style.strokeWidth / 2)
            return outer.contains(p) && !(inner.width > 0 && inner.height > 0 && inner.contains(p))
        case .pen(let pts):
            return Self.polylineHit(pts, p, tolerance + style.strokeWidth / 2)
        case .highlighter(let pts):
            return Self.polylineHit(pts, p, tolerance + style.strokeWidth * Self.highlighterWidthFactor / 2)
        case .text, .pixelate:
            return boundingBox.insetBy(dx: -tolerance, dy: -tolerance).contains(p)
        }
    }

    func translated(by d: CGVector) -> Annotation {
        var copy = self
        func move(_ p: CGPoint) -> CGPoint { CGPoint(x: p.x + d.dx, y: p.y + d.dy) }
        switch kind {
        case .arrow(let a, let b): copy.kind = .arrow(from: move(a), to: move(b))
        case .rect(let r): copy.kind = .rect(r.offsetBy(dx: d.dx, dy: d.dy))
        case .ellipse(let r): copy.kind = .ellipse(r.offsetBy(dx: d.dx, dy: d.dy))
        case .pen(let pts): copy.kind = .pen(pts.map(move))
        case .highlighter(let pts): copy.kind = .highlighter(pts.map(move))
        case .text(let o, let s): copy.kind = .text(origin: move(o), string: s)
        case .pixelate(let r, let b): copy.kind = .pixelate(r.offsetBy(dx: d.dx, dy: d.dy), blockSize: b)
        }
        return copy
    }

    private static func polylineHit(_ pts: [CGPoint], _ p: CGPoint, _ tol: CGFloat) -> Bool {
        if pts.count == 1 { return hypot(pts[0].x - p.x, pts[0].y - p.y) <= tol }
        for i in 1..<pts.count where distance(from: p, toSegment: pts[i - 1], pts[i]) <= tol {
            return true
        }
        return false
    }

    static func distance(from p: CGPoint, toSegment a: CGPoint, _ b: CGPoint) -> CGFloat {
        let abx = b.x - a.x, aby = b.y - a.y
        let len2 = abx * abx + aby * aby
        if len2 == 0 { return hypot(p.x - a.x, p.y - a.y) }
        let t = max(0, min(1, ((p.x - a.x) * abx + (p.y - a.y) * aby) / len2))
        let proj = CGPoint(x: a.x + t * abx, y: a.y + t * aby)
        return hypot(p.x - proj.x, p.y - proj.y)
    }
}
```

```swift
import AppKit

/// Draws annotations into a CGContext whose user space is image pixels with a
/// top-left origin (y grows downward). Used by both the canvas and the exporter.
enum AnnotationRenderer {
    static func draw(_ annotations: [Annotation], in ctx: CGContext, pixelateImage: (Annotation) -> CGImage?) {
        for a in annotations {
            ctx.saveGState()
            ctx.setStrokeColor(a.style.color.cgColor)
            ctx.setFillColor(a.style.color.cgColor)
            ctx.setLineWidth(a.style.strokeWidth)
            ctx.setLineCap(.round)
            ctx.setLineJoin(.round)
            switch a.kind {
            case .arrow(let from, let to):
                drawArrow(from: from, to: to, width: a.style.strokeWidth, in: ctx)
            case .rect(let r):
                ctx.stroke(r)
            case .ellipse(let r):
                ctx.strokeEllipse(in: r)
            case .pen(let pts):
                strokePolyline(pts, in: ctx)
            case .highlighter(let pts):
                ctx.setBlendMode(.multiply)
                ctx.setAlpha(0.4)
                ctx.setLineWidth(a.style.strokeWidth * Annotation.highlighterWidthFactor)
                ctx.setLineCap(.butt)
                strokePolyline(pts, in: ctx)
            case .text(let origin, let string):
                drawText(string, at: origin, style: a.style, in: ctx)
            case .pixelate(let r, _):
                if let img = pixelateImage(a) {
                    // CGImages draw bottom-up; flip locally so the crop lands upright.
                    ctx.translateBy(x: r.minX, y: r.maxY)
                    ctx.scaleBy(x: 1, y: -1)
                    ctx.draw(img, in: CGRect(origin: .zero, size: r.size))
                }
            }
            ctx.restoreGState()
        }
    }

    private static func strokePolyline(_ pts: [CGPoint], in ctx: CGContext) {
        guard let first = pts.first else { return }
        if pts.count == 1 {
            ctx.move(to: first)
            ctx.addLine(to: first)
        } else {
            ctx.move(to: first)
            for p in pts.dropFirst() { ctx.addLine(to: p) }
        }
        ctx.strokePath()
    }

    private static func drawArrow(from: CGPoint, to: CGPoint, width: CGFloat, in ctx: CGContext) {
        let dx = to.x - from.x, dy = to.y - from.y
        let length = hypot(dx, dy)
        guard length > 0.5 else { return }
        let headLength = max(12, width * 4)
        let headHalfWidth = headLength * 0.5
        let ux = dx / length, uy = dy / length
        let base = CGPoint(x: to.x - ux * headLength, y: to.y - uy * headLength)
        ctx.move(to: from)
        ctx.addLine(to: base)
        ctx.strokePath()
        let left = CGPoint(x: base.x - uy * headHalfWidth, y: base.y + ux * headHalfWidth)
        let right = CGPoint(x: base.x + uy * headHalfWidth, y: base.y - ux * headHalfWidth)
        ctx.move(to: to)
        ctx.addLine(to: left)
        ctx.addLine(to: right)
        ctx.closePath()
        ctx.fillPath()
    }

    private static func drawText(_ string: String, at origin: CGPoint, style: AnnotationStyle, in ctx: CGContext) {
        let attrs: [NSAttributedString.Key: Any] = [
            .font: NSFont.boldSystemFont(ofSize: style.fontSize),
            .foregroundColor: NSColor(cgColor: style.color.cgColor) ?? .red,
        ]
        let gc = NSGraphicsContext(cgContext: ctx, flipped: true)
        NSGraphicsContext.saveGraphicsState()
        NSGraphicsContext.current = gc
        NSAttributedString(string: string, attributes: attrs).draw(at: origin)
        NSGraphicsContext.restoreGraphicsState()
    }
}
```

```swift
import CoreGraphics
import Foundation

/// Produces pixelated crops of the base image through the Rust core, cached per rect.
final class PixelateService {
    private let base: CGImage
    private var cache: [UUID: (rect: CGRect, blockSize: Int, image: CGImage)] = [:]

    init(base: CGImage) {
        self.base = base
    }

    func image(for annotation: Annotation) -> CGImage? {
        guard case .pixelate(let rect, let blockSize) = annotation.kind else { return nil }
        let integral = rect.integral.intersection(CGRect(x: 0, y: 0, width: base.width, height: base.height))
        guard integral.width >= 1, integral.height >= 1 else { return nil }
        if let hit = cache[annotation.id], hit.rect == integral, hit.blockSize == blockSize {
            return hit.image
        }
        guard let crop = base.cropping(to: integral) else { return nil }
        let w = crop.width, h = crop.height
        var rgba = [UInt8](repeating: 0, count: w * h * 4)
        guard let ctx = CGContext(data: &rgba, width: w, height: h, bitsPerComponent: 8, bytesPerRow: w * 4,
                                  space: CGColorSpace(name: CGColorSpace.sRGB)!,
                                  bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue) else { return nil }
        ctx.draw(crop, in: CGRect(x: 0, y: 0, width: w, height: h))
        guard let out = try? pixelate(pixels: Data(rgba), width: UInt32(w), height: UInt32(h),
                                      x: 0, y: 0, w: UInt32(w), h: UInt32(h),
                                      blockSize: UInt32(max(1, blockSize))) else { return nil }
        guard let provider = CGDataProvider(data: out as CFData),
              let image = CGImage(width: w, height: h, bitsPerComponent: 8, bitsPerPixel: 32, bytesPerRow: w * 4,
                                  space: CGColorSpace(name: CGColorSpace.sRGB)!,
                                  bitmapInfo: CGBitmapInfo(rawValue: CGImageAlphaInfo.premultipliedLast.rawValue),
                                  provider: provider, decode: nil, shouldInterpolate: false, intent: .defaultIntent)
        else { return nil }
        cache[annotation.id] = (integral, blockSize, image)
        return image
    }
}
```

```swift
import AppKit
import Combine

@MainActor
final class EditorDocument: ObservableObject {
    let image: CGImage
    let undoManager = UndoManager()
    let pixelateService: PixelateService

    @Published private(set) var annotations: [Annotation] = []
    @Published var selectedID: UUID?
    @Published var tool: EditorTool = .arrow
    @Published var style = AnnotationStyle()
    @Published private(set) var isDirty = false
    private(set) var lastSavedURL: URL?

    init(image: CGImage) {
        self.image = image
        self.pixelateService = PixelateService(base: image)
        undoManager.levelsOfUndo = 100
    }

    func add(_ a: Annotation) {
        replaceAnnotations(annotations + [a], actionName: "Add \(describe(a))")
    }

    /// Replaces the whole list and registers an undo step restoring the old list.
    func replaceAnnotations(_ new: [Annotation], actionName: String) {
        let old = annotations
        guard old != new else { return }
        undoManager.registerUndo(withTarget: self) { target in
            target.replaceAnnotations(old, actionName: actionName)
        }
        undoManager.setActionName(actionName)
        annotations = new
        isDirty = true
    }

    /// Live update during a drag; no undo step. Pair with `replaceAnnotations` on mouse up.
    func setAnnotationsWithoutUndo(_ new: [Annotation]) {
        annotations = new
    }

    func removeSelected() {
        guard let id = selectedID else { return }
        replaceAnnotations(annotations.filter { $0.id != id }, actionName: "Delete")
        selectedID = nil
    }

    func markSaved(to url: URL) {
        lastSavedURL = url
        isDirty = false
    }

    func rasterize() -> CGImage? {
        ImageComposer.render(base: image, annotations: annotations) { [pixelateService] in
            pixelateService.image(for: $0)
        }
    }

    private func describe(_ a: Annotation) -> String {
        switch a.kind {
        case .arrow: return "Arrow"
        case .rect: return "Rectangle"
        case .ellipse: return "Ellipse"
        case .pen: return "Pen Stroke"
        case .highlighter: return "Highlight"
        case .text: return "Text"
        case .pixelate: return "Pixelate"
        }
    }
}
```

```swift
import AppKit
import Combine

/// Scales the screenshot to fit, draws annotations on top, and turns mouse input
/// into annotations according to the document's current tool.
final class AnnotationCanvasView: NSView, NSTextFieldDelegate {
    private let document: EditorDocument
    private var cancellables: Set<AnyCancellable> = []

    private var draft: Annotation?
    private var dragStart: CGPoint?
    private var snapshot: [Annotation] = []
    private var lastDragPoint: CGPoint?
    private var textField: NSTextField?
    private var textOrigin: CGPoint?

    init(document: EditorDocument) {
        self.document = document
        super.init(frame: .zero)
        wantsLayer = true
        layer?.backgroundColor = NSColor.windowBackgroundColor.cgColor
        document.objectWillChange
            .receive(on: RunLoop.main)
            .sink { [weak self] _ in
                guard let self else { return }
                self.needsDisplay = true
                self.window?.invalidateCursorRects(for: self)
            }
            .store(in: &cancellables)
    }

    required init?(coder: NSCoder) { fatalError("not used") }

    override var isFlipped: Bool { true }
    override var acceptsFirstResponder: Bool { true }

    // MARK: Geometry

    private var imageSize: CGSize { CGSize(width: document.image.width, height: document.image.height) }

    private var scale: CGFloat {
        guard bounds.width > 0, bounds.height > 0 else { return 1 }
        return min(bounds.width / imageSize.width, bounds.height / imageSize.height, 1)
    }

    private var imageRect: CGRect {
        let s = scale
        let size = CGSize(width: imageSize.width * s, height: imageSize.height * s)
        return CGRect(x: (bounds.width - size.width) / 2, y: (bounds.height - size.height) / 2,
                      width: size.width, height: size.height)
    }

    private func imagePoint(_ event: NSEvent) -> CGPoint {
        let v = convert(event.locationInWindow, from: nil)
        let r = imageRect
        return CGPoint(x: (v.x - r.minX) / scale, y: (v.y - r.minY) / scale)
    }

    private func viewPoint(_ p: CGPoint) -> CGPoint {
        let r = imageRect
        return CGPoint(x: r.minX + p.x * scale, y: r.minY + p.y * scale)
    }

    override func resetCursorRects() {
        let cursor: NSCursor
        switch document.tool {
        case .select: cursor = .arrow
        case .text: cursor = .iBeam
        default: cursor = .crosshair
        }
        addCursorRect(bounds, cursor: cursor)
    }

    // MARK: Drawing

    override func draw(_ dirtyRect: NSRect) {
        guard let ctx = NSGraphicsContext.current?.cgContext else { return }
        let r = imageRect
        ctx.saveGState()
        ctx.translateBy(x: r.minX, y: r.maxY)
        ctx.scaleBy(x: 1, y: -1)
        ctx.interpolationQuality = .high
        ctx.draw(document.image, in: CGRect(origin: .zero, size: r.size))
        ctx.restoreGState()

        ctx.saveGState()
        ctx.translateBy(x: r.minX, y: r.minY)
        ctx.scaleBy(x: scale, y: scale)
        ctx.clip(to: CGRect(origin: .zero, size: imageSize))
        var all = document.annotations
        if let draft { all.append(draft) }
        AnnotationRenderer.draw(all, in: ctx) { [document] in document.pixelateService.image(for: $0) }
        if let id = document.selectedID, let sel = document.annotations.first(where: { $0.id == id }) {
            ctx.setStrokeColor(NSColor.controlAccentColor.cgColor)
            ctx.setLineWidth(1.5 / scale)
            ctx.setLineDash(phase: 0, lengths: [6 / scale, 4 / scale])
            ctx.stroke(sel.boundingBox.insetBy(dx: -6 / scale, dy: -6 / scale))
        }
        ctx.restoreGState()
    }

    // MARK: Mouse

    override func mouseDown(with event: NSEvent) {
        window?.makeFirstResponder(self)
        commitTextEntry()
        let p = imagePoint(event)
        snapshot = document.annotations
        dragStart = p
        lastDragPoint = p
        switch document.tool {
        case .select:
            document.selectedID = document.annotations.last { $0.hitTest(p, tolerance: 6 / scale) }?.id
        case .text:
            beginTextEntry(at: p)
        case .arrow:
            draft = Annotation(kind: .arrow(from: p, to: p), style: document.style)
        case .rect:
            draft = Annotation(kind: .rect(CGRect(origin: p, size: .zero)), style: document.style)
        case .ellipse:
            draft = Annotation(kind: .ellipse(CGRect(origin: p, size: .zero)), style: document.style)
        case .pixelate:
            draft = Annotation(kind: .pixelate(CGRect(origin: p, size: .zero), blockSize: 12), style: document.style)
        case .pen:
            draft = Annotation(kind: .pen([p]), style: document.style)
        case .highlighter:
            draft = Annotation(kind: .highlighter([p]), style: document.style)
        }
        needsDisplay = true
    }

    override func mouseDragged(with event: NSEvent) {
        let p = imagePoint(event)
        guard let start = dragStart else { return }
        if document.tool == .select {
            guard let id = document.selectedID, let last = lastDragPoint else { return }
            let d = CGVector(dx: p.x - last.x, dy: p.y - last.y)
            document.setAnnotationsWithoutUndo(document.annotations.map { $0.id == id ? $0.translated(by: d) : $0 })
            lastDragPoint = p
            return
        }
        guard var d = draft else { return }
        let frame = SelectionGeometry.rect(from: start, to: p, constrainSquare: event.modifierFlags.contains(.shift))
        switch d.kind {
        case .arrow(let from, _): d.kind = .arrow(from: from, to: p)
        case .rect: d.kind = .rect(frame)
        case .ellipse: d.kind = .ellipse(frame)
        case .pixelate(_, let b): d.kind = .pixelate(frame, blockSize: b)
        case .pen(var pts): pts.append(p); d.kind = .pen(pts)
        case .highlighter(var pts): pts.append(p); d.kind = .highlighter(pts)
        case .text: break
        }
        draft = d
        needsDisplay = true
    }

    override func mouseUp(with event: NSEvent) {
        defer { draft = nil; dragStart = nil; lastDragPoint = nil; needsDisplay = true }
        if document.tool == .select {
            if document.selectedID != nil, snapshot != document.annotations {
                let moved = document.annotations
                document.setAnnotationsWithoutUndo(snapshot)
                document.replaceAnnotations(moved, actionName: "Move")
            }
            return
        }
        guard let d = draft, isUsable(d) else { return }
        document.add(d)
    }

    private func isUsable(_ a: Annotation) -> Bool {
        switch a.kind {
        case .pen(let pts), .highlighter(let pts): return pts.count >= 2
        case .text: return true
        default:
            let b = a.boundingBox
            return b.width >= 2 || b.height >= 2
        }
    }

    // MARK: Keyboard

    override func keyDown(with event: NSEvent) {
        switch event.keyCode {
        case 51, 117: // Delete, Forward Delete
            if document.selectedID != nil { document.removeSelected() } else { super.keyDown(with: event) }
        case 53: // Escape
            document.selectedID = nil
            commitTextEntry()
        default:
            if let ch = event.charactersIgnoringModifiers?.lowercased().first,
               event.modifierFlags.intersection([.command, .option, .control]).isEmpty,
               let tool = EditorTool.allCases.first(where: { $0.key == ch }) {
                document.tool = tool
            } else {
                super.keyDown(with: event)
            }
        }
    }

    // MARK: Text entry

    private func beginTextEntry(at p: CGPoint) {
        let field = NSTextField(frame: CGRect(origin: viewPoint(p), size: CGSize(width: 240, height: document.style.fontSize * scale * 1.4)))
        field.isBordered = false
        field.drawsBackground = false
        field.focusRingType = .none
        field.font = NSFont.boldSystemFont(ofSize: document.style.fontSize * scale)
        field.textColor = NSColor(cgColor: document.style.color.cgColor)
        field.placeholderString = "Text"
        field.delegate = self
        addSubview(field)
        window?.makeFirstResponder(field)
        textField = field
        textOrigin = p
    }

    private func commitTextEntry() {
        guard let field = textField, let origin = textOrigin else { return }
        let string = field.stringValue.trimmingCharacters(in: .whitespacesAndNewlines)
        field.removeFromSuperview()
        textField = nil
        textOrigin = nil
        if !string.isEmpty {
            document.add(Annotation(kind: .text(origin: origin, string: string), style: document.style))
        }
    }

    func control(_ control: NSControl, textView: NSTextView, doCommandBy selector: Selector) -> Bool {
        if selector == #selector(NSResponder.insertNewline(_:)) {
            commitTextEntry()
            window?.makeFirstResponder(self)
            return true
        }
        if selector == #selector(NSResponder.cancelOperation(_:)) {
            textField?.stringValue = ""
            commitTextEntry()
            window?.makeFirstResponder(self)
            return true
        }
        return false
    }

    func controlTextDidEndEditing(_ obj: Notification) {
        commitTextEntry()
    }
}
```

```swift
import AppKit
import SwiftUI
import UniformTypeIdentifiers

@MainActor
final class EditorWindowController: NSWindowController, NSWindowDelegate {
    let document: EditorDocument
    private let preferences: PreferencesStore
    var onClose: (() -> Void)?

    init(image: CGImage, preferences: PreferencesStore) {
        self.document = EditorDocument(image: image)
        self.preferences = preferences

        let screenFrame = NSScreen.main?.visibleFrame ?? CGRect(x: 0, y: 0, width: 1440, height: 900)
        let scale = NSScreen.main?.backingScaleFactor ?? 2
        let maxSize = CGSize(width: screenFrame.width * 0.8, height: screenFrame.height * 0.8 - 44)
        let natural = CGSize(width: CGFloat(image.width) / scale, height: CGFloat(image.height) / scale)
        let fit = min(1, maxSize.width / natural.width, maxSize.height / natural.height)
        let content = CGSize(width: max(480, natural.width * fit), height: max(320, natural.height * fit + 44))

        let window = NSWindow(contentRect: CGRect(origin: .zero, size: content),
                              styleMask: [.titled, .closable, .miniaturizable, .resizable],
                              backing: .buffered, defer: false)
        window.title = "Screenshot"
        window.isReleasedWhenClosed = false
        window.minSize = CGSize(width: 480, height: 320)
        super.init(window: window)
        window.delegate = self

        let root = EditorView(document: document, actions: EditorActions(
            copy: { [weak self] in self?.copyToClipboard() },
            save: { [weak self] in self?.saveReportingErrors() },
            saveAs: { [weak self] in self?.saveAs() }
        ))
        window.contentView = NSHostingView(rootView: root)
        window.center()
    }

    required init?(coder: NSCoder) { fatalError("not used") }

    func present() {
        NSApp.activate(ignoringOtherApps: true)
        showWindow(nil)
        window?.makeKeyAndOrderFront(nil)
    }

    // MARK: Actions

    func copyToClipboard() {
        guard let image = document.rasterize() else { return }
        ImageExporter.copyToClipboard(image)
    }

    /// Saves to the last saved location, or a new timestamped file in the preferred folder.
    @discardableResult
    func save() throws -> URL {
        guard let image = document.rasterize() else { throw ExportError.encodingFailed }
        let url = document.lastSavedURL
            ?? FileNamer.uniqueURL(in: preferences.preferences.saveFolderURL, ext: "png")
        try ImageExporter.writePNG(image, to: url)
        document.markSaved(to: url)
        return url
    }

    private func saveReportingErrors() {
        do {
            try save()
        } catch {
            ErrorPresenter.present(error, title: "Could not save")
            saveAs()
        }
```

`CaniClip/Recording/FrameConverter.swift`:
```swift
import CoreVideo
import Foundation

/// A tightly packed 32-bit BGRA frame (no row padding).
struct BGRAFrame {
    let pixels: Data
    let width: Int
    let height: Int
}

enum FrameConverter {
    /// Copies a 32BGRA pixel buffer into a packed buffer, removing any row stride padding.
    static func bgraFrame(from buffer: CVPixelBuffer) -> BGRAFrame? {
        guard CVPixelBufferGetPixelFormatType(buffer) == kCVPixelFormatType_32BGRA else { return nil }
        CVPixelBufferLockBaseAddress(buffer, .readOnly)
        defer { CVPixelBufferUnlockBaseAddress(buffer, .readOnly) }
        guard let base = CVPixelBufferGetBaseAddress(buffer) else { return nil }

        let width = CVPixelBufferGetWidth(buffer)
        let height = CVPixelBufferGetHeight(buffer)
        let stride = CVPixelBufferGetBytesPerRow(buffer)
        let rowBytes = width * 4
        var data = Data(count: rowBytes * height)
        data.withUnsafeMutableBytes { dst in
            guard let out = dst.baseAddress else { return }
            if stride == rowBytes {
                memcpy(out, base, rowBytes * height)
            } else {
                for y in 0..<height {
                    memcpy(out + y * rowBytes, base + y * stride, rowBytes)
                }
            }
        }
        return BGRAFrame(pixels: data, width: width, height: height)
    }
}
```

`CaniClip/Recording/GifRecordingSink.swift`:
```swift
import Foundation

/// Feeds frames to the Rust GifEncoder on a serial queue. If the encoder falls
/// more than `maxPending` frames behind, new frames are dropped; because every
/// frame carries its real presentation time the GIF's timing stays correct.
final class GifRecordingSink: @unchecked Sendable {
    static let maxPending = 10

    private let encoder: GifEncoder
    private let queue = DispatchQueue(label: "com.caniclip.gif-sink", qos: .userInitiated)
    private let lock = NSLock()
    private var pendingCount = 0
    private var firstTimestamp: Double?
    private var failure: Error?
    private var _accepted = 0
    private var _dropped = 0

    var acceptedFrames: Int { lock.withLock { _accepted } }
    var droppedFrames: Int { lock.withLock { _dropped } }

    init(settings: GifSettings) throws {
        encoder = try GifEncoder(settings: settings)
    }

    func append(_ frame: BGRAFrame, presentationTime: Double) {
        let timestamp: Double
        lock.lock()
        if failure != nil {
            lock.unlock()
            return
        }
        if pendingCount >= Self.maxPending {
            _dropped += 1
            lock.unlock()
            return
        }
        pendingCount += 1
        if firstTimestamp == nil { firstTimestamp = presentationTime }
        timestamp = presentationTime - (firstTimestamp ?? presentationTime)
        lock.unlock()

        queue.async { [self] in
            do {
                try encoder.addFrame(pixels: frame.pixels, width: UInt32(frame.width), height: UInt32(frame.height),
                                     format: .bgra, timestampSecs: timestamp)
                lock.withLock { _accepted += 1 }
            } catch {
                lock.withLock { failure = error }
            }
            lock.withLock { pendingCount -= 1 }
        }
    }

    /// Waits for every queued frame, then finalises the GIF at `url`.
    func finish(to url: URL) async throws -> GifSummary {
        try await withCheckedThrowingContinuation { continuation in
            queue.async { [self] in
                if let failure = lock.withLock({ self.failure }) {
                    encoder.cancel()
                    continuation.resume(throwing: failure)
                    return
                }
                do {
                    continuation.resume(returning: try encoder.finish(outputPath: url.path))
                } catch {
                    continuation.resume(throwing: error)
                }
            }
        }
    }

    func cancel() {
        queue.async { [self] in encoder.cancel() }
    }
}
```

```swift
import CoreGraphics

enum PanelPlacement {
    /// Origin (global AppKit coordinates) for a panel of `panelSize` sitting just
    /// below `region`, or above it when there is no room, kept inside `visibleFrame`.
    static func origin(panelSize: CGSize, nearRegion region: CGRect, visibleFrame: CGRect, gap: CGFloat) -> CGPoint {
        let margin: CGFloat = 8
        var x = region.midX - panelSize.width / 2
        x = min(max(x, visibleFrame.minX + margin), visibleFrame.maxX - panelSize.width - margin)
        var y = region.minY - gap - panelSize.height
        if y < visibleFrame.minY + margin {
            y = region.maxY + gap
        }
        return CGPoint(x: x, y: y)
    }
}
```

```swift
import AppKit
import ScreenCaptureKit

/// Runs one area recording at a time: SCStream → StreamOutput → GifRecordingSink → file.
@MainActor
final class RecordingController: NSObject, SCStreamDelegate {
    struct Output {
        let url: URL
        let summary: GifSummary
    }

    enum RecordingError: LocalizedError {
        case alreadyRecording
        case streamStopped(Error)

        var errorDescription: String? {
            switch self {
            case .alreadyRecording: return "A recording is already in progress."
            case .streamStopped(let e): return "The screen recording stopped: \(e.localizedDescription)"
            }
        }
    }

    private(set) var isRecording = false
    var onFinished: ((Result<Output, Error>) -> Void)?

    private let preferences: PreferencesStore
    private var stream: SCStream?
    private var output: StreamOutput?
    private var sink: GifRecordingSink?
    private var frameWindow: RegionFrameWindow?
    private var hudPanel: FloatingPanel?
    private let hudModel = RecordingHUDModel()
    private var timer: Timer?
    private var startedAt: Date?

    init(preferences: PreferencesStore) {
        self.preferences = preferences
    }

    func start(globalRect: CGRect, screen: NSScreen) async throws {
        guard !isRecording else { throw RecordingError.alreadyRecording }
        let prefs = preferences.preferences

        let content = try await SCShareableContent.excludingDesktopWindows(false, onScreenWindowsOnly: true)
        guard let display = content.displays.first(where: { $0.displayID == screen.displayID }) else {
            throw CaptureError.displayNotFound
        }
        let filter = ScreenCapturer.filterExcludingSelf(display: display, content: content)
        let geometry = DisplayGeometry(frame: screen.frame, scale: screen.backingScaleFactor)
        let source = CaptureGeometry.sourceRect(globalRect: globalRect, display: geometry)
        let px = CaptureGeometry.pixelSize(pointSize: source.size, scale: geometry.scale)

        let config = SCStreamConfiguration()
        config.sourceRect = source
        config.width = px.width
        config.height = px.height
        config.pixelFormat = kCVPixelFormatType_32BGRA
        config.minimumFrameInterval = CMTime(value: 1, timescale: CMTimeScale(max(1, prefs.gifFPS)))
        config.showsCursor = prefs.showCursorInRecording
        config.queueDepth = 5
        config.capturesAudio = false

        let settings = GifSettings(maxWidth: prefs.gifMaxWidth.maxWidthValue, maxHeight: nil,
                                   quality: UInt8(min(100, max(1, prefs.gifQuality))), fast: false, repeat: 0)
        let sink = try GifRecordingSink(settings: settings)
        let output = StreamOutput(sink: sink)
        let stream = SCStream(filter: filter, configuration: config, delegate: self)
        try stream.addStreamOutput(output, type: .screen, sampleHandlerQueue: output.queue)
        try await stream.startCapture()

        self.stream = stream
        self.output = output
        self.sink = sink
        isRecording = true
        startedAt = Date()
        showChrome(globalRect: globalRect, screen: screen, maxSeconds: prefs.maxRecordingSeconds)
    }

    func stop() {
        guard isRecording, let stream, let sink else { return }
        isRecording = false
        hideChrome()
        let folder = preferences.preferences.saveFolderURL
        Task { [weak self] in
            do {
                try await stream.stopCapture()
            } catch {
                // Stopping after the stream already ended is not a failure for the GIF.
            }
            let url = FileNamer.uniqueURL(in: folder, ext: "gif")
            do {
                let summary = try await sink.finish(to: url)
                self?.onFinished?(.success(Output(url: url, summary: summary)))
            } catch {
                self?.onFinished?(.failure(error))
            }
            self?.stream = nil
            self?.output = nil
            self?.sink = nil
        }
    }

    // MARK: SCStreamDelegate

    nonisolated func stream(_ stream: SCStream, didStopWithError error: Error) {
        Task { @MainActor in
            guard isRecording else { return }
            isRecording = false
            hideChrome()
            sink?.cancel()
            self.stream = nil
            output = nil
            sink = nil
            onFinished?(.failure(RecordingError.streamStopped(error)))
        }
    }

    // MARK: Chrome

    private func showChrome(globalRect: CGRect, screen: NSScreen, maxSeconds: Int) {
        let frame = RegionFrameWindow(globalRect: globalRect)
        frame.setStyle(.recording)
        frame.orderFrontRegardless()
        frameWindow = frame

        hudModel.elapsed = 0
        let hud = FloatingPanel(content: RecordingHUDView(model: hudModel) { [weak self] in self?.stop() },
                                size: RecordingHUDView.size)
        let origin = PanelPlacement.origin(panelSize: RecordingHUDView.size, nearRegion: globalRect,
                                           visibleFrame: screen.visibleFrame, gap: 12)
        hud.show(at: origin)
        hudPanel = hud

        timer = Timer.scheduledTimer(withTimeInterval: 0.5, repeats: true) { [weak self] _ in
            Task { @MainActor in
                guard let self, let startedAt = self.startedAt else { return }
                self.hudModel.elapsed = Date().timeIntervalSince(startedAt)
                if self.hudModel.elapsed >= Double(maxSeconds) { self.stop() }
            }
        }
    }

    private func hideChrome() {
        timer?.invalidate()
        timer = nil
        hudPanel?.orderOut(nil)
        hudPanel = nil
        frameWindow?.orderOut(nil)
        frameWindow = nil
        startedAt = nil
    }
}
```

```markdown
# CaniClip

A small menu bar app for macOS to screenshot, annotate, and record a screen area to GIF.
Swift (AppKit + SwiftUI + ScreenCaptureKit) for the app, Rust for GIF encoding and
image processing, joined by UniFFI.

## Requirements

- macOS 15 or later on Apple Silicon
- Xcode 26 with command line tools
- Rust via rustup (`curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`)
- XcodeGen (`brew install xcodegen`)

## Build and run

    ./scripts/bootstrap.sh   # builds the Rust core, writes Local.xcconfig, generates CaniClip.xcodeproj
    ./scripts/run.sh         # builds Debug and launches the app

Or open `CaniClip.xcodeproj` after bootstrapping and press Run. The Xcode build
re-runs `scripts/build-rust.sh` before compiling Swift.

On first launch macOS asks for Screen Recording permission. Grant it, then quit
and reopen the app.

## Default shortcuts

| Action | Shortcut |
|---|---|
| Capture area | ⌘⇧7 |
| Record area to GIF | ⌘⇧8 |
| Capture full screen | ⌘⇧9 |

Change them in Settings from the menu bar icon.

## Tests

    (cd core && cargo test)
    xcodebuild test -project CaniClip.xcodeproj -scheme CaniClip -destination 'platform=macOS,arch=arm64'

## Layout

- `core/` Rust crate `caniclip-core`: GifEncoder over gifski, pixelate, UniFFI exports
- `CaniClip/` Swift app sources; `CaniClip/Generated/` holds UniFFI output (gitignored)
- `project.yml` XcodeGen definition; `scripts/` build helpers
- `docs/superpowers/` design spec, implementation plan and smoke test
```
