# Security

**Found a security problem? Don't open a public issue.**

Report it privately: [open a security advisory](https://github.com/Flamentist/caniclip/security/advisories/new). Only maintainers can see it.

Include:
- what's wrong
- steps to reproduce
- the macOS version and CaniClip commit

We'll reply as soon as we can. CaniClip is a hobby project, so there's no fixed response time.

## Supported versions

Only the latest code on `main`.
